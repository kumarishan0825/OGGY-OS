# OGGY-OS 🐾

A web-based desktop OS themed around *Oggy and the Cockroaches*, built with plain HTML, CSS and vanilla JavaScript. No login, no password: open the link and try it.

**Live demo:** https://YOUR-USERNAME.github.io/YOUR-REPO/

---

## Features
- Multiple **draggable windows**: Google, Notes, Calculator, Command Prompt, Oggy game
- **Dock** with a magnify-on-hover effect, floating app labels and "app is open" dots
- Smooth window pop-in animation
- Notes app with PDF export, a working calculator and a mini command prompt
- **CyberLab** (my own addition): threat-intel lookup, password breach check, hash lab, CyberChef and a CVE/reference search *(delete this line if you don't include cyber.js)*

---

## Tech
HTML5, CSS3, vanilla JavaScript.
